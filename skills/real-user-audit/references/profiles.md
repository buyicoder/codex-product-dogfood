# Profiles

## ai-chat

Use for assistant, prompt-entry, agent, and chat products. Expected signals include chat input, send action, upload affordance, voice affordance, empty state, and recoverable errors.

## student-learning

Use for study, tutoring, homework, practice, and classroom products. Expected signals include learning entry, question input, formula affordance, upload affordance, voice affordance, empty state, and recoverable errors.

Student-learning profiles should declare critical bbox controls for composer, status, upload, voice, and send. These controls are treated as high-priority layout surfaces on mobile viewports.
